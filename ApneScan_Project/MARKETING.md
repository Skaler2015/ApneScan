## 1) छोटा विवरण (Short description, ~50 words)

ApneScan is a 100% free, open-source document scanner for Windows 10/11 with a
Hindi + English interface. Scan to searchable PDF from network (eSCL), USB
(TWAIN/WIA), webcam or a phone photo; compress PDFs to 200KB–2MB for portal
uploads; and share on WhatsApp/Email. Everything runs offline — no ads,
no tracking.

## 2) लंबा विवरण (Long description)

ApneScan is a free, open-source Windows application that turns paper into clean,
searchable PDFs. It works with network scanners over WiFi/LAN (eSCL — no drivers;
HP, Canon, Epson, Brother), USB scanners (TWAIN/WIA) with ADF duplex, a webcam,
or photos taken on a phone (shadows removed, page straightened).

Key features:
- Scan to searchable PDF with Hindi + English OCR (Tesseract)
- Compress any PDF to exact 200KB / 500KB / 1MB / 2MB targets — ideal for
  government-portal uploads with strict size limits
- Full PDF toolkit: merge, split, page editor (crop/erase/text/arrow/
  perspective), sign/stamp, watermark, page numbers, password remove,
  PDF → Word / Excel / JPG, folder → PDF
- Smart auto-naming of repeated forms (English + Hindi) with bill/claim number
  and date; built-in file manager with instant search inside PDFs
- WhatsApp & Email sharing; blank-page removal, auto-crop, deskew, auto-orient
- Fully offline — documents never leave the PC. No ads, no accounts, no cloud.

A free Windows alternative to NAPS2 and to phone apps like CamScanner, with a
Hindi-first interface — built for shops, offices, clinics/hospitals, schools and
CSC centres in India.
