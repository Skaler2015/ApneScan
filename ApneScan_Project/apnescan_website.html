FAQ · Frequently asked questions

Common questions

Is ApneScan really free?

Yes — 100% free, no ads, no hidden charges. None of your documents ever leave your PC.

Which scanners are supported?

Network (WiFi/LAN) scanners work without drivers via eSCL — HP, Canon, Epson, Brother. USB scanners via TWAIN/WIA, with ADF duplex support.

Does it do Hindi OCR?

Yes — it creates searchable PDFs with both English and Hindi text that you can search and copy.

Can it compress PDFs?

Yes — shrink any PDF to 200KB / 500KB / 1MB / 2MB targets, perfect for portals with upload size limits.

Phone photo to PDF?

Yes — import a phone photo of a document; shadows are removed and it becomes a clean, scan-like PDF.

Share on WhatsApp?

Yes — File → Share sends a saved PDF straight to WhatsApp or Email.

Why the SmartScreen warning?

Windows shows it for new unsigned apps — click "More info → Run anyway". The code is open-source on GitHub.

Scanner not showing?

Run Settings → "Find scanner" (auto-discovery), or try TWAIN/WIA scan methods. Make sure the scanner is on and on the same network.
