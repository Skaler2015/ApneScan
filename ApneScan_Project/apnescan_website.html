FAQ · अक्सर पूछे जाने वाले सवाल

Common questions

Kya ApneScan free hai?

हाँ — 100% free, no ads, no hidden charges. आपका कोई भी document आपके PC से बाहर नहीं जाता।

Kaun se scanner chalte hain?

Network (WiFi/LAN) scanners बिना driver के (eSCL) — HP, Canon, Epson, Brother. USB scanners TWAIN/WIA से। ADF duplex support के साथ।

Hindi OCR hota hai?

हाँ — Hindi + English searchable PDF बनती है जिसका text search और copy हो सकता है।

PDF compress hoti hai?

हाँ — किसी भी PDF को 200KB / 500KB / 1MB / 2MB तक छोटा करें — portal uploads के लिए perfect.

Phone-photo se PDF?

हाँ — phone की document-photo import करो; shadow हटकर scan जैसी साफ PDF बनती है।

WhatsApp par bhej sakte hain?

हाँ — File → Share/Bhejo से saved PDF सीधे WhatsApp या Email में।

SmartScreen warning kyon?

नई unsigned app पर Windows की normal चेतावनी है — "More info → Run anyway" दबाएँ। Code GitHub पर public (open-source) है।

Scanner not showing?

Settings → "Scanner khud dhoondo" चलाएँ, या Scan method में TWAIN/WIA try करें। Scanner ON और उसी network पर हो।
