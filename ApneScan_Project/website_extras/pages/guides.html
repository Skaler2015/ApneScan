How-to Guides

1. How to scan a document to PDF

  1. Open ApneScan and pick your scanner profile (or run Settings → Find scanner).
  2. Put your pages in the feeder and press Scan (or Enter).
  3. Pages appear as thumbnails; drag to reorder, rotate or delete any.
  4. Click Save PDF — done. Turn on OCR first for a searchable PDF.
💡 Tip: press F2 on a page to name it once — the same form will name itself automatically next time.

2. How to compress a PDF to 200KB

  1. Go to Tools → PDF chhota karo (compress).
  2. Choose the current pages or pick any existing PDF.
  3. Select a target size: 200KB, 500KB, 1MB or 2MB.
  4. Save — ApneScan shrinks it just under your target, perfect for portal uploads.
💡 Portals often limit uploads to 1–2 MB. 200KB is great for ID cards and single pages.

3. How to send a PDF on WhatsApp

  1. Save your PDF first.
  2. Go to File → Share / Bhejo → WhatsApp.
  3. WhatsApp opens and the file is copied — pick a chat and press Ctrl+V, or drag the file into the chat.
💡 The same menu also has Email — it opens a draft with the PDF attached (Outlook), ready to send.
